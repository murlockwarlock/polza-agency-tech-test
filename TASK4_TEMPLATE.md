# Задача 4 — заполнить лично, без AI

Этот файл намеренно содержит только структуру. Ответы нужно написать своими словами перед отправкой.

## IDE и модели

Какой IDE и какими LLM-моделями пользуюсь сейчас? Что изменилось за последние шесть месяцев и почему?

## Подписки

Какие подписки оплачиваю каждый месяц? Сколько это стоит и каких лимитов реально хватает для полной рабочей недели?

## Сравнение моделей и инструментов

Какой одинаковый набор задач использую для сравнения? Какие критерии измеряю: качество первого решения, число итераций, тесты, скорость, стоимость, объём ручных правок?

## Тесты новой функции

Какие unit, integration, e2e, regression, security и performance проверки потребую? Какие негативные сценарии считаю обязательными?

## Разрешения coding-агента

Что агент может читать и менять локально? Какие действия с сетью, секретами, production-базой, удалением данных, git push и deploy всегда требуют ручного подтверждения?

## CI/CD

Какие тесты пишу автоматически? Что должно пройти до merge, перед deploy и после deploy? Как устроены rollback, миграции и smoke-check?
